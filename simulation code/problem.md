1. 为什么更容易选出 superset  
搜索目标没有惩罚“多余 block”,没有任何复杂度惩罚，所以模型只要误差更低，就算它多带了无关 block，也照样会赢。但从“恢复真实结构”的角度看，我们真正想要的可能是：在误差差不多的情况下，优先选更小、更干净的架构。
2. 多一个 block，不只是“多一个输入”，而是“多一整套编码器 + 更多参数”  
b1+b2 参数更少，b1+b2+b3 参数更多，所以我们这不是单纯在比较“哪些 block 有用”，而是在同时比较：输入子集，模型容量，优化难度
3. 我们的 ground truth 是“最小充分集”，不是“唯一最优集”  
如果真实函数只依赖 b1,b2，那么任何包含 b1,b2 的结构都可以把额外 block 的作用学成接近 0。
4. 如何修正  
给大架构加惩罚，让不同架构参数预算一致，固定训练集 / 验证集
